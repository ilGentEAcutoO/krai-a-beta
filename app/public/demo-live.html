Under the hoodThe voice path, the models, and a .wav upload

Mic audio (PCM 24 kHz) → wss /api/voice/live → the VoiceCall Durable Object → Meta's Voice WebSocket (Muse Voice Transcribe). Each finished sentence is judged with the whole call so far by Muse Spark 1.2 (/api/verdict/turn); grey cases go to Muse Wonder (/api/verdict/escalate). Code rules close at once on a hard demand (OTP, app install, transfer now). The Meta key never leaves the server.

Voice output only: Gemini TTS, because Meta's API has no TTS; every decision is a Meta model. Fixed lines are pre-recorded; live trap lines are synthesized only for text our server wrote; if that fails, the browser voice takes over.

In the browser the call is half-duplex: words spoken over the assistant are lost. Every model route sits behind a session token (Cloudflare Turnstile), per-IP rate limits, a daily cap and a kill switch.
