Our reasoning, not a statistic: gangs switch numbers, so a blocklist misses the first call from a new number. The script is what gives them away, so KRAI-A listens to the script and picks up instead.

The difference

Why not a blocklist
or a call screener?

Blocklists know numbers. Call screeners hand the decision back to you. KRAI-A judges the script and hangs up itself — and every number behind that is on /proof, misses included.

Screeners protect you and let you decide. KRAI-A protects someone you love — the person who decides worst under pressure — and tells you afterwards.

  1. Hangs up itself without cutting off real callers No real caller judged scam across 4 sealed sets. Spark decides; a fixed rule in code acts on it. Evidence Limit: 116 is small, and the calls are synthetic.
  2. Measured in a way it can't fool itself Sealed sets are hash-pre-registered in git and run once per build, and the misses are published: on the stress set, Malay 0/4 and Tagalog 0/6. Evidence Limit: the stress set ran on 100 of 236 calls.
  3. A training loop that compounds The AI-vs-AI arena ran 504 games: 1 of 185 real callers wrongly hung up, 0/57 on the holdout after fixes. Evidence Limit: the data is AI-written, with no real victim calls yet.
  4. The output is evidence, not a warning Every call ends with a report for the family: who the caller claimed to be, the tactic, and the account numbers, LINE IDs and links they gave, in their own words (links defanged). Example Limit: chat delivery is contract-tested, not live-verified.
  5. Cost and speed are measured $0.0081 per call ($8.14 per 1,000); judging takes 2.5 s per sentence at p50; a daily cap and a kill switch are in place. Evidence Limit: slower than the old build (0.27 s).

One call

What happens when a stranger calls

The assistant keeps talking, so there is no dead air. Every decision is a model judgment plus code.

  1. 1

    It says what it is

    Every call opens with the same line: an automated assistant is answering for the owner, and the call is recorded.

  2. 2

    Every sentence is judged

    Muse Voice Transcribe hears the caller live, Muse Spark judges each finished sentence, grey cases go to Muse Wonder. Spark decides; a fixed rule in code acts on it.

  3. 3

    Scam: hang up or stall

    A polite close, or a trap that asks the caller to repeat and spell things out. It never agrees to pay, never says a code, never claims to be a person.

  4. 4

    A report for the family

    Who the caller claimed to be, the trick, every account or LINE id they gave (with their exact words), and what to do next. Copy or share it.

Under the hood

What a call passes through, and how it gets better

Gemini does one job, speaking out loud, because the Meta Model API has no text-to-speech. Timings and cost are for judging only; transcription is priced separately.

Quotes or nothing

Evidence, intel and the claimed identity are dropped unless the caller really said it.

The key stays on the server

The browser never sees the model API key. Every model route has rate limits, a daily cap and a kill switch.

Never pretends to be a person

Every spoken line passes a guard first: no agreeing to pay, no codes, no details about the household.

Honest limits

  • A web demo, not a phone line. Try a call in your browser or fork it. A real phone line through call forwarding is next (not built).
  • Slower than the old judge. Spark takes 2.5 s per sentence; the old build took 0.27 s.
  • 4 scams slipped through. On the stress set, B30 blocked 31/59, held 24 as a message and let 4 through as real callers. Malay 0/4, Tagalog 0/6.
  • Synthetic data. Test calls are AI-written, with no real victim calls yet; the real-audio test voices are TTS.

Full list on /proof and /arena

AI disclosure and privacy

  • Every call opens by saying it is automated and that the call is recorded. A code guard stops any generated line that claims to be a real person.
  • Audio is streamed to the Meta Model API for live transcription and processed under Meta's API terms; we don't store audio. A call's text is kept server-side only during the call and deleted when you hang up (at most 15 minutes later), with no outside read path.
  • No account and no phone number. IPs are kept only as salted hashes for rate limits. The model API key never reaches the browser.
