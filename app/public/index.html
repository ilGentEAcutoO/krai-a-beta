One call

What happens when a stranger calls

The assistant keeps talking, so there is no dead air. Every decision is a Meta model plus code.

  1. 1

    It says what it is

    Every call opens with the same line: an automated assistant is answering for the owner, and the call is recorded.

  2. 2

    Every sentence is judged

    Muse Voice Transcribe hears the caller live, Muse Spark judges each finished sentence, grey cases go to Muse Wonder, and code picks the action.

  3. 3

    Scam: hang up or stall

    A polite close, or a 10-minute trap that asks the caller to repeat and spell things out. It never agrees to pay, never says a code, never claims to be a person.

  4. 4

    A report for the family

    Who the caller claimed to be, the trick, every account or LINE id they gave (with their exact words), and what to do next. Copy or share it.

Under the hood

Every decision is a Meta model

Gemini does one job, speaking out loud, because Meta's API has no text-to-speech.

Meta · earMuse Voice Transcribemuse-voice-transcribe-1.0Hears Thai in real time through a Durable Object that keeps the key on the server.
Meta · judgeMuse Sparkmuse-spark-1.2 · 1.31.2 judges every sentence; 1.3 writes the trap lines and the case report.
Meta · second opinionMuse Wondermuse-wonder-1.0Grey zone only. It can raise suspicion but never clear a call that asked for money or codes. It also plays the callers in the arena.
CodeThe policypolicy.jsModels return labels and numbers; code is the only place a verdict becomes an action.
Voice onlyGemini TTSgemini-3.8-flash-ttsSpeaks lines our server wrote or pre-recorded. It decides nothing.

Quotes or nothing

Evidence, intel and the claimed identity are dropped unless the caller really said it.

The key stays on the server

The browser never sees the Meta key. Every model route has rate limits, a daily cap and a kill switch.

Never pretends to be a person

Every spoken line passes a guard first: no agreeing to pay, no codes, no details about the household.
