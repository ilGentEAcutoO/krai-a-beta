The problem

A fresh number every time.
The same script.

Call-centre gangs phone older people, pose as police, a bank or a government office, and talk them into moving savings to a “safe account” or reading out a one-time code. The family finds out after the money is gone. Caller-ID apps and number blocklists miss a fresh number.

One call

What happens when a stranger calls

The assistant keeps talking, so there is no dead air. Every decision is a model judgment plus code.

  1. 1

    It says what it is

    Every call opens with the same line: an automated assistant is answering for the owner, and the call is recorded.

  2. 2

    Every sentence is judged

    Muse Voice Transcribe hears the caller live, Muse Spark judges each finished sentence, grey cases go to Muse Wonder, and code picks the action.

  3. 3

    Scam: hang up or stall

    A polite close, or a 10-minute trap that asks the caller to repeat and spell things out. It never agrees to pay, never says a code, never claims to be a person.

  4. 4

    A report for the family

    Who the caller claimed to be, the trick, every account or LINE id they gave (with their exact words), and what to do next. Copy or share it.

Quotes or nothing

Evidence, intel and the claimed identity are dropped unless the caller really said it.

The key stays on the server

The browser never sees the model API key. Every model route has rate limits, a daily cap and a kill switch.

Never pretends to be a person

Every spoken line passes a guard first: no agreeing to pay, no codes, no details about the household.

Honest limits

  • A web demo, not a phone line. This demo does not send the report to anyone; the family copies or shares it. Chat delivery exists for forks (above), not live-verified.
  • Slower than the old judge. Spark takes 2.5 s per sentence against about 0.27 s; the first real reply is slower too (3.0 s vs 1.2 s).
  • Over-cautious with foreign-language callers. In the 9-language set, 24 of 62 real callers got a message taken instead of being cleared, and 2 scams ended as a message (none was cleared). Languages other than English and Mandarin have 5 calls each.
  • 4 scams slipped through. On the adversarial stress set, B30 blocked 31/59; 24 more were held as a message (no hang-up) and 4 were put through as real callers. Malay and Tagalog are weakest there (0/4 and 0/6 blocked). The real-audio test voices are TTS, not people.

AI disclosure and privacy

  • Every call opens by saying it is automated and that the call is recorded. A code guard stops any generated line that claims to be a real person.
  • Audio is streamed to the Meta Model API for live transcription and processed under Meta's API terms; we don't store audio. A call's text is kept server-side only during the call and deleted when you hang up (at most 15 minutes later), with no outside read path.
  • No account and no phone number. IPs are kept only as salted hashes for rate limits. The model API key never reaches the browser.
