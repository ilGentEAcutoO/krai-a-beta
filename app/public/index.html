An automated receptionist that answers scam calls for Thai parents

KRAI-A (ใครอะ, “who is it?”) picks up instead of an elderly parent, says it is automated, and judges every caller sentence live with Meta’s Muse models. A scam caller gets hung up on or kept busy, and the family gets a case report they can share.

What happens on a call

  1. It says what it isEvery call opens with the same spoken line. ระบบผู้ช่วยรับสายอัตโนมัติรับสายแทนเจ้าของเบอร์ สายนี้มีการบันทึก ขอทราบชื่อและธุระค่ะAn automated assistant is answering for the owner. This call is recorded. Your name and business, please?
  2. Every sentence is judgedMuse Voice Transcribe hears Thai in real time; Muse Spark judges each finished sentence; code turns that into an action. Grey cases go to Muse Wonder.
  3. Scam: hang up or play for timeTrap mode asks the caller to slow down, repeat and spell things out for up to 10 minutes. It never agrees to pay, never says a code, and never claims to be a person.
  4. A case report for the familyWho the caller claimed to be, the tactic, every account or LINE id they gave with their exact words, and next steps in Thai. Copy or share it; nothing is sent automatically.

Meta models, and where each one works

Muse Voice Transcribemuse-voice-transcribe-1.0

The ear: a realtime socket through a Cloudflare Durable Object that holds the key. Thai with code-switching.

Muse Sparkmuse-spark-1.2 muse-spark-1.3

Spark 1.2 (effort minimal) judges every sentence; Spark 1.3 writes the trap-mode lines and the case report. Strict JSON schemas; code checks every quote.

Muse Wondermuse-wonder-1.0

A second opinion for the grey zone only. It can raise suspicion but can never clear a call that asked for money or codes.

Code decidesModels return labels and numbers; policy.js is the only place a verdict becomes an action.
Quotes or nothingEvidence, intel and the claimed identity are dropped unless the caller really said it.
Key stays on the serverThe browser never sees the Meta key. Every model route has rate limits, a daily cap and a kill switch.

What was built here, and the two exceptions

This repo was started after the Meta kickoff (first commit Oct 27, 2026) and everything that runs on this site was built between Oct 27 and Nov 4. An older KRAI-A build from the Google Cloud AI Builder Cup is not part of this entry. Two things were carried over, and both are marked in the repo:

  • The old judge, copied into app/src/baseline/, is used only as the ruler on /proof and /showdown. No live code imports it.
  • 57 of the 120 train calls were ported from the old build ("source": "v2-port"). They are train data only; all 35 sealed test calls are new.
