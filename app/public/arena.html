      How the arena works

      How the arena works
      • Each caller is muse-wonder-1.0 with one persona card; it hears KRAI-A's real replies before each turn (max 8 turns).
      • The KRAI-A side is the same code production runs, in-process: T1 code rules → Muse Spark 1.2 judges every turn → code policy → Muse Wonder for borderline cases → follow-up question / close / trap (Spark 1.3).
      • Block = closed as a scam or trapped · Escalate = unsure, a message for the owner to decide · Allow = closed as a real call with a normal message.
      • Every name, number and account in these transcripts is invented by the persona model.
      • 30% of games were held out (hash of id) before any tuning; fixes used the other 70% only.
