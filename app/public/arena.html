      วิธีวัด / How the arena works
      • ผู้โทรแต่ละสายคือ muse-wonder-1.0 ที่ได้ "บทบาท" หนึ่งบท แล้วฟังคำตอบจริงของ KRAI-A ก่อนพูดเทิร์นถัดไป (สูงสุด 8 เทิร์น) · Each caller is muse-wonder-1.0 with one persona card; it hears KRAI-A's real replies before each turn (max 8 turns).
      • ฝั่ง KRAI-A คือโค้ดชุดเดียวกับ production รันในเครื่อง: กฎโค้ด T1 → Muse Spark 1.2 ตัดสินทุกเทิร์น → policy ในโค้ด → Muse Wonder เคสก้ำกึ่ง → คำถามถามต่อ / ปิดสาย / กับดัก (Spark 1.3) · KRAI-A side: the same code production runs, in-process.
      • Block = ปิดสายแบบมิจหรือเปิดกับดัก · Escalate = ยังไม่แน่ใจ ฝากข้อความให้เจ้าของตัดสินเอง · Allow = ปิดเป็นสายจริง (ฝากข้อความว่าเป็นธุระปกติ). สายมิจที่ถูก = Block; สายจริงที่ถูก = Allow; สายจริงที่โดน Block = วางสายผิด
      • ข้อมูลทุกอย่างในบทสนทนาแต่งขึ้นโดย AI (ชื่อ เบอร์ บัญชี) ไม่มีข้อมูลคนจริง · Every name, number and account in these transcripts is invented by the persona model.
      • สาย 30% ถูกกันไว้เป็น holdout ก่อนเริ่มแก้ระบบ (แบ่งด้วย hash ของ id) การแก้ใช้เฉพาะ 70% · 30% of games were held out (hash of id) before any tuning; fixes used the other 70% only.
